# MODEL v3.1.0: WITHDRAWN

v3.1 withdrawn: its accounting change (inventory default) expanded the scope to the existing stock; superseded by v3.2,
which keeps the v3.0 cause-based accounting.

The non-methodological fixes of v3.1 (release accounting, history split, the fast re-occupation sensitivity row, the
r_L6 check with A_1, the figure fixes and the documentation corrections) are carried into MODEL v3.2.0
(branch `release/model-v3.2.0`, created from `release/model-v3.0.0`). This branch is kept, unchanged otherwise, for
the record; tag `v3.1.0-withdrawn`.
